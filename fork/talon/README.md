# Talon files moved

The Talon files (voice shell commands, personal overrides, the disabled Handy bridge) now live in the community fork,
`kolaf/community`, in its `kolaf/` folder, so that cloning the fork on a new machine brings them along. See
`kolaf/README.md` there. They are no longer kept here, to avoid two copies drifting apart.

(The `hv` script itself stays in this repo: `fork/voice-shell/hv`.)
